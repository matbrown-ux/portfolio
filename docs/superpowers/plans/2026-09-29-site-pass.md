# Site-wide Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Home, About, Services, Contact, and the global chrome (navbar, mobile menu, footer) onto the interaction foundation, with keyword `h1`s, five disciplines from one data source, a crawlable Home hero with a rotating discipline line and portrait parallax, and a Services discipline index that links each discipline to its proof case study.

**Architecture:** One typed data module (`src/content/disciplines.ts`) feeds every discipline surface. Pure helpers (parallax offset, rotator index, open-row-from-hash, contact validation, focus-trap cycling) live in small tested `.ts` modules. New components (`Reveal`, `PortraitMedia`, `DisciplineRotator`, `DisciplineIndex`, `SkipLink`) sit on the existing foundation (`useScrollReveal`, `RevealText`, `Magnetic`, `ProjectCover`/`ProjectMeta`). GSAP owns scroll/timeline work; Motion owns pointer/state; never both on one element.

**Tech Stack:** React 18, Vite 5, vite-react-ssg, TypeScript, Tailwind CSS v4, GSAP 3 + @gsap/react (via `src/lib/gsap.ts`), motion 11, react-router-dom 6, Vitest + Testing Library (jsdom), Netlify Forms.

**Spec:** `docs/superpowers/specs/2026-09-29-site-pass-design.md`

## Global Constraints

- Vite + vite-react-ssg project, not Next.js. Branch: `feat/site-pass` (stacked on `feat/work-index`).
- No em dashes (`—`) in visible copy. Never fabricate facts, metrics, response times, or process claims. Existing copy is reused verbatim unless this plan gives new copy; new discipline copy carries `// TODO: owner review`.
- Brand tokens only: `directors-black`, `secondary-dark`, `vermilion`, `vermilion-hover`, `cream`, `muted-prose`, `border-line`. Vermilion is the single accent.
- No `transform` hover lifts on dark cards (hover = vermilion border + glow). GSAP tweens of dark surfaces use `force3D: false`.
- Every animation has a static fallback under `prefers-reduced-motion`.
- GSAP only via `src/lib/gsap.ts`; `useGSAP` with `dependencies` uses `revertOnUpdate: true`. Motion owns pointer/state animation. No element animated by both.
- Eases/durations/springs come from `src/lib/motion.ts` (`EASE`, `GSAP_EASE`, `DURATION`, `SPRING`); no local bezier arrays in files this plan touches.
- Page `h1`s via `RevealText` (single text copy). Decorative art `aria-hidden`; images of the owner keep `alt="Mathew Brown"`.
- Logic modules have basenames distinct from components (macOS case-insensitive imports). Import components extensionless.
- Router tests use `src/test/TestRouter.tsx`; pages with `SEO` need `HelmetProvider`. Test output must be pristine.
- TDD: every source change starts with a failing test; commits staging source also stage a test. Never bypass hooks; never add `Test-Exempt`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never kill other dev servers by name; the owner runs one on port 5180.

## Review Focus

1. **Unknown or malformed hash on `/services`** (`#nope`, `#%E0%A4%A`): the first discipline stays open, nothing throws. Pinned in Tasks 2 and 8.
2. **`/contact?service=<unknown>`**: no preselection; the select shows "Select a service". Pinned in Task 3.
3. **Required contact fields containing only whitespace**: treated as empty, blocked with an error, focus moves to the first one. Pinned in Tasks 3 and 11.
4. **Mobile menu open, then a route change**: it closes, page scroll is restored, and focus returns to the toggle. Pinned in Task 13.
5. **Two disciplines sharing one proof case study** ('Aiwi for SEO/AEO and Brand; The Booking Flow for Agentic and SaaS): both proof cards render with unique element ids and correctly named links. Pinned in Task 8.

`src/components/portrait/parallax.ts`:

```ts
export interface Point {
  x: number
  y: number
}
export interface Size {
  w: number
  h: number
}

const clampUnit = (v: number) => Math.max(-1, Math.min(1, v))

/**
 * Offset (px) that moves an element opposite the pointer: 0 at the viewport
 * center, up to `max` at the edges, clamped for pointers outside the viewport.
 */
export function parallaxOffset(pointer: Point, viewport: Size, max = 16): Point {
  if (viewport.w <= 0 || viewport.h <= 0) return { x: 0, y: 0 }
  const nx = clampUnit((pointer.x / viewport.w) * 2 - 1)
  const ny = clampUnit((pointer.y / viewport.h) * 2 - 1)
  // + 0 normalizes -0 to 0.
  return { x: -nx * max + 0, y: -ny * max + 0 }
}
```

```ts
/**
 * Which discipline row should be open for a URL hash: the named slug if it is
 * one of `slugs`, otherwise `fallback`. Malformed escapes fall back too.
 */
export function resolveOpenSlug(hash: string, slugs: string[], fallback: string | null): string | null {
  let slug: string
  try {
    slug = decodeURIComponent(hash.replace(/^#/, ''))
  } catch {
    return fallback
  }
  return slugs.includes(slug) ? slug : fallback
}
```

```ts
export type ContactField = 'name' | 'email' | 'company' | 'projectType' | 'budget' | 'message'

/** Required fields, in form order (focus goes to the first invalid one). */
export const REQUIRED_CONTACT_FIELDS: ContactField[] = ['name', 'email', 'company', 'projectType', 'budget']

const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

const EMPTY_MESSAGE: Record<Exclude<ContactField, 'email' | 'message'>, string> = {
  name: 'Please enter your name.',
  company: 'Please enter your company.',
  projectType: 'Please choose a project type.',
  budget: 'Please choose a budget range.',
}

/** Error message for a contact field value, or null when it is valid. */
export function validateContactField(field: ContactField, value: string): string | null {
  const v = value.trim()
  if (field === 'message') return null
  if (field === 'email') {
    if (!v) return 'Please enter your email.'
    return EMAIL.test(v) ? null : 'Please enter a valid email address.'
  }
  return v ? null : EMPTY_MESSAGE[field]
}

/** The discipline title named by `?service=<slug>`, for preselecting the project type. */
export function serviceFromQuery(search: string, items: { slug: string; title: string }[]): string | null {
  const slug = new URLSearchParams(search).get('service')
  return items.find((d) => d.slug === slug)?.title ?? null
}
```

`src/components/nav/focusTrap.ts`:

```ts
/**
 * Next index to focus inside a focus trap of `count` elements. `current` is -1
 * when focus is outside the trap. Returns -1 when nothing is focusable.
 */
export function nextFocusIndex(current: number, count: number, shift: boolean): number {
  if (count <= 0) return -1
  if (current < 0) return shift ? count - 1 : 0
  return shift ? (current - 1 + count) % count : (current + 1) % count
}
```

```tsx
import type { ReactNode } from 'react'
import { gsap } from '../../lib/gsap'
import { DURATION, GSAP_EASE } from '../../lib/motion'
import { useScrollReveal } from './useScrollReveal'

type RevealTag = 'div' | 'section' | 'li' | 'p'

interface RevealProps {
  as?: RevealTag
  className?: string
  /** Extra seconds before this element's reveal (for simple staggers). */
  delay?: number
  children: ReactNode
}

/**
 * Fades and lifts its content in once on scroll-in, after the page curtain has
 * cleared. Replaces FadeIn/StaggerList on redesigned pages. Reduced motion:
 * rendered as-is.
 */
export function Reveal({ as: Tag = 'div', className, delay = 0, children }: RevealProps) {
  const ref = useScrollReveal<HTMLElement>(
    (el) =>
      gsap.from(el, {
        autoAlpha: 0,
        y: 16,
        duration: DURATION.base,
        delay,
        ease: GSAP_EASE.out,
        force3D: false,
      }),
    { deps: [delay] }
  )
  return (
    <Tag ref={ref as never} className={className}>
      {children}
    </Tag>
  )
}
```

`src/components/portrait/PortraitMedia.tsx`:

```tsx
import { useEffect, useRef } from 'react'
import { motion, useMotionValue, useSpring } from 'motion/react'
import { gsap, useGSAP } from '../../lib/gsap'
import { GSAP_EASE, SPRING } from '../../lib/motion'
import { useEntranceDelay } from '../PageCurtain'
import { useMediaQuery } from '../../hooks/useMediaQuery'
import { useReducedMotion } from '../../hooks/useReducedMotion'
import { parallaxOffset } from './parallax'

interface PortraitMediaProps {
  src: string
  /** Positions the whole composition (absolute, sized per page). */
  className?: string
  /** Positions the circle; Motion moves this wrapper for parallax. */
  circleWrapperClassName: string
  /** Positions the portrait image. */
  imageWrapperClassName: string
  imageClassName: string
  imageWidth?: number
  imageHeight?: number
}

/**
 * The owner's portrait over a dark circle (Home hero, About header). On load the
 * image grows in, then the circle blooms (GSAP, curtain-aware, force3D off). On
 * a fine pointer the circle drifts gently against the pointer (Motion, outer
 * wrapper only, so GSAP and Motion never touch the same element).
 */
export function PortraitMedia({
  src,
  className,
  circleWrapperClassName,
  imageWrapperClassName,
  imageClassName,
  imageWidth = 600,
  imageHeight = 900,
}: PortraitMediaProps) {
  const rootRef = useRef<HTMLDivElement>(null)
  const entranceDelay = useEntranceDelay()
  const fine = useMediaQuery('(pointer: fine)')
  const reduced = useReducedMotion()
  const parallax = fine && !reduced
  const x = useMotionValue(0)
  const y = useMotionValue(0)
  const sx = useSpring(x, SPRING.preview)
  const sy = useSpring(y, SPRING.preview)

  useEffect(() => {
    if (!parallax) {
      x.set(0)
      y.set(0)
      return
    }
    const move = (e: PointerEvent) => {
      const o = parallaxOffset({ x: e.clientX, y: e.clientY }, { w: window.innerWidth, h: window.innerHeight })
      x.set(o.x)
      y.set(o.y)
    }
    window.addEventListener('pointermove', move, { passive: true })
    return () => window.removeEventListener('pointermove', move)
  }, [parallax, x, y])

  useGSAP(
    () => {
      const mm = gsap.matchMedia()
      mm.add('(prefers-reduced-motion: no-preference)', () => {
        gsap
          .timeline({ delay: 0.15 + entranceDelay, defaults: { ease: GSAP_EASE.out, force3D: false } })
          .from('[data-portrait-image]', { autoAlpha: 0, scale: 0.85, duration: 1.1, transformOrigin: 'bottom center' }, 0)
          .from('[data-portrait-circle]', { autoAlpha: 0, scale: 0.78, duration: 1.2, transformOrigin: 'center center' }, 0.3)
      })
    },
    { scope: rootRef, dependencies: [entranceDelay], revertOnUpdate: true }
  )

  return (
    <div ref={rootRef} className={className}>
      <motion.div
        aria-hidden="true"
        data-parallax={parallax ? 'on' : 'off'}
        className={circleWrapperClassName}
        style={parallax ? { x: sx, y: sy } : undefined}
      >
        <div data-portrait-circle className="h-full w-full rounded-full bg-secondary-dark" />
      </motion.div>
      <div className={imageWrapperClassName}>
        <img
          data-portrait-image
          src={src}
          alt="Mathew Brown"
          className={imageClassName}
          width={imageWidth}
          height={imageHeight}
        />
      </div>
    </div>
  )
}
```

Note: Tailwind v4 `translate-*` utilities set the CSS `translate` property, which composes with Motion's `transform`, so a wrapper can keep its centering classes and still take Motion x/y. The browser pass (Task 15) confirms it.

```tsx
import { useEffect, useState } from 'react'
import { AnimatePresence, motion } from 'motion/react'
import { useReducedMotion } from '../../hooks/useReducedMotion'
import { DURATION, EASE } from '../../lib/motion'
import { nextRotatorIndex } from './rotatorIndex'

// TODO: owner review
export const ROTATOR_LINES = [
  'Designing interfaces.',
  'Ranking in search and AI answers.',
  'Automating workflows.',
  'Building brands.',
  'Shipping SaaS.',
]

interface DisciplineRotatorProps {
  /** One sentence covering every line, read by assistive tech instead of the rotation. */
  srLabel: string
  lines?: string[]
  /** Milliseconds between lines. */
  interval?: number
  className?: string
}

/**
 * A display line that cycles through the disciplines with a masked slide-up.
 * Decorative (aria-hidden) with a single sr-only sentence; pauses while the tab
 * is hidden; holds the first line under reduced motion.
 */
export function DisciplineRotator({ srLabel, lines = ROTATOR_LINES, interval = 2800, className = '' }: DisciplineRotatorProps) {
  const reduced = useReducedMotion()
  const [index, setIndex] = useState(0)

  useEffect(() => {
    if (reduced || lines.length < 2) return
    const id = window.setInterval(() => {
      if (document.visibilityState === 'visible') setIndex((i) => nextRotatorIndex(i, lines.length))
    }, interval)
    return () => window.clearInterval(id)
  }, [reduced, lines.length, interval])

  const shown = reduced ? 0 : index
  const line = lines[shown]

  return (
    <p className={className}>
      <span className="sr-only">{srLabel}</span>
      <span aria-hidden="true" data-rotator-index={shown} className="relative block overflow-hidden pb-[0.1em]">
        <AnimatePresence mode="wait" initial={false}>
          <motion.span
            key={line}
            className="block"
            initial={reduced ? false : { y: '110%' }}
            animate={{ y: '0%' }}
            exit={reduced ? undefined : { y: '-110%' }}
            transition={{ duration: DURATION.base, ease: EASE.outQuint }}
          >
            {line}
          </motion.span>
        </AnimatePresence>
      </span>
    </p>
  )
}
```

```tsx
import { useEffect, useRef, useState } from 'react'
import { motion } from 'motion/react'
import { Magnetic } from '../interaction/Magnetic'
import { Button } from '../ui/Button'
import { ProofCard } from './ProofCard'
import { resolveOpenSlug } from './disciplineState'
import { disciplines as allDisciplines, type Discipline } from '../../content/disciplines'
import { getCaseStudyBySlug } from '../../lib/content'
import { useReducedMotion } from '../../hooks/useReducedMotion'
import { DURATION, EASE } from '../../lib/motion'

/**
 * Services as numbered disclosure rows. One row open at a time (the first by
 * default, or the one named by #<slug>). Collapsed panels stay in the DOM
 * (inert) so every discipline's copy is crawlable.
 */
export function DisciplineIndex({ items = allDisciplines }: { items?: Discipline[] }) {
  const reduced = useReducedMotion()
  const slugKey = items.map((d) => d.slug).join('|')
  const [open, setOpen] = useState<string | null>(items[0]?.slug ?? null)

  useEffect(() => {
    const slugs = slugKey.split('|')
    const apply = () => {
      const target = resolveOpenSlug(window.location.hash, slugs, null)
      if (!target) return
      setOpen(target)
      document
        .getElementById(`discipline-${target}`)
        ?.scrollIntoView?.({ behavior: reduced ? 'auto' : 'smooth', block: 'start' })
    }
    apply()
    window.addEventListener('hashchange', apply)
    return () => window.removeEventListener('hashchange', apply)
  }, [slugKey, reduced])

  return (
    <ol role="list" className="border-t border-border-line">
      {items.map((d) => (
        <DisciplineRow
          key={d.slug}
          discipline={d}
          open={open === d.slug}
          reduced={reduced}
          onToggle={() => setOpen((current) => (current === d.slug ? null : d.slug))}
        />
      ))}
    </ol>
  )
}

interface DisciplineRowProps {
  discipline: Discipline
  open: boolean
  reduced: boolean
  onToggle: () => void
}

function DisciplineRow({ discipline: d, open, reduced, onToggle }: DisciplineRowProps) {
  const panelRef = useRef<HTMLDivElement>(null)
  const buttonId = `discipline-${d.slug}-button`
  const panelId = `discipline-${d.slug}-panel`
  const proof = d.proofSlug ? getCaseStudyBySlug(d.proofSlug) : undefined

  // React 18 has no first-class `inert`; set the attribute directly.
  useEffect(() => {
    panelRef.current?.toggleAttribute('inert', !open)
  }, [open])

  return (
    <li id={`discipline-${d.slug}`} className="border-b border-border-line">
      <div className="grid items-center gap-x-10 md:grid-cols-[minmax(0,1fr)_minmax(0,22rem)]">
        <h2 className="m-0">
          <button
            id={buttonId}
            type="button"
            aria-expanded={open}
            aria-controls={panelId}
            onClick={onToggle}
            className="group flex w-full items-center gap-6 py-8 text-left focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-vermilion md:gap-10"
          >
            <span
              className={`font-bold leading-none transition-colors duration-300 ${open ? 'text-vermilion' : 'text-muted-prose group-hover:text-cream'}`}
              style={{ fontSize: 'clamp(2rem, 4vw, 3.5rem)', letterSpacing: '-0.03em' }}
            >
              {d.number}
            </span>
            <span className="flex-1 text-2xl font-semibold tracking-tight text-cream md:text-3xl">{d.title}</span>
            <span aria-hidden="true" className="text-2xl text-vermilion">
              {open ? '×' : '+'}
            </span>
          </button>
        </h2>
        <p className="hidden text-sm leading-relaxed text-muted-prose md:block">{d.blurb}</p>
      </div>

      <motion.div
        ref={panelRef}
        id={panelId}
        role="region"
        aria-labelledby={buttonId}
        aria-hidden={!open}
        initial={false}
        animate={{ height: open ? 'auto' : 0, opacity: open ? 1 : 0 }}
        transition={{ duration: reduced ? 0 : DURATION.base, ease: EASE.outQuint }}
        className="overflow-hidden"
      >
        <div className="grid gap-10 pb-12 md:grid-cols-[minmax(0,1fr)_minmax(0,22rem)] md:gap-16">
          <div>
            <p className="mb-8 max-w-prose leading-relaxed text-muted-prose">{d.description}</p>
            <ul className="mb-10 space-y-3">
              {d.deliverables.map((item) => (
                <li key={item} className="flex items-start gap-4 text-sm text-cream">
                  <span aria-hidden="true" className="mt-1.5 h-3 w-px flex-shrink-0 bg-vermilion" />
                  {item}
                </li>
              ))}
            </ul>
            <Magnetic>
              <Button href={`/contact?service=${d.slug}`}>{d.cta}</Button>
            </Magnetic>
          </div>
          {proof && <ProofCard caseStudy={proof} idPrefix={`proof-${d.slug}`} />}
        </div>
      </motion.div>
    </li>
  )
}
```

```tsx
import { useEffect, useRef, useState } from 'react'
import { NavLink, useLocation } from 'react-router-dom'
import { AnimatePresence, motion } from 'motion/react'
import { SocialLinks } from './SocialLinks'
import { Button } from '../ui/Button'
import { nextFocusIndex } from './focusTrap'
import { useReducedMotion } from '../../hooks/useReducedMotion'
import { DURATION, EASE } from '../../lib/motion'

const navItems = [
  { label: 'About', to: '/about' },
  { label: 'Services', to: '/services' },
  { label: 'Work', to: '/work' },
  { label: 'Blog', to: '/blog' },
  { label: 'Contact', to: '/contact' },
]

/**
 * Full-screen mobile navigation under the navbar. Keyboard-safe: focus is
 * trapped between the toggle and the menu, Escape closes, focus returns to the
 * toggle, page scroll is locked while open, and route changes close it.
 */
export function MobileMenu() {
  const [open, setOpen] = useState(false)
  const reduced = useReducedMotion()
  const { pathname } = useLocation()
  const toggleRef = useRef<HTMLButtonElement>(null)
  const panelRef = useRef<HTMLDivElement>(null)
  const wasOpen = useRef(false)

  useEffect(() => {
    setOpen(false)
  }, [pathname])

  useEffect(() => {
    if (!open) {
      if (wasOpen.current) toggleRef.current?.focus()
      wasOpen.current = false
      return
    }
    wasOpen.current = true
    const previousOverflow = document.body.style.overflow
    document.body.style.overflow = 'hidden'

    const focusables = () =>
      [toggleRef.current, ...Array.from(panelRef.current?.querySelectorAll<HTMLElement>('a[href], button:not([disabled])') ?? [])].filter(
        (el): el is HTMLElement => el !== null
      )

    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
        e.preventDefault()
        setOpen(false)
        return
      }
      if (e.key !== 'Tab') return
      const items = focusables()
      const next = nextFocusIndex(items.indexOf(document.activeElement as HTMLElement), items.length, e.shiftKey)
      if (next < 0) return
      e.preventDefault()
      items[next].focus()
    }
    document.addEventListener('keydown', onKey)
    return () => {
      document.removeEventListener('keydown', onKey)
      document.body.style.overflow = previousOverflow
    }
  }, [open])

  return (
    <div className="md:hidden">
      <button
        ref={toggleRef}
        type="button"
        onClick={() => setOpen((o) => !o)}
        aria-label={open ? 'Close menu' : 'Open menu'}
        aria-expanded={open}
        aria-controls="mobile-menu"
        className="p-1 text-cream"
      >
        {open ? (
          <svg width="18" height="18" viewBox="0 0 16 16" fill="none" aria-hidden="true">
            <line x1="1" y1="1" x2="15" y2="15" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" />
            <line x1="15" y1="1" x2="1" y2="15" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" />
          </svg>
        ) : (
          <svg width="22" height="16" viewBox="0 0 20 14" fill="none" aria-hidden="true">
            <line x1="0" y1="2" x2="20" y2="2" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" />
            <line x1="0" y1="12" x2="13" y2="12" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" />
          </svg>
        )}
      </button>

      <AnimatePresence>
        {open && (
          <motion.div
            ref={panelRef}
            key="mobile-menu"
            id="mobile-menu"
            role="dialog"
            aria-modal="true"
            aria-label="Menu"
            className="fixed inset-0 z-[55] flex flex-col bg-directors-black px-6 pb-12 pt-24"
            initial={reduced ? false : { opacity: 0 }}
            animate={{ opacity: 1 }}
            exit={{ opacity: 0, transition: { duration: reduced ? 0 : DURATION.fast } }}
            transition={{ duration: reduced ? 0 : DURATION.fast }}
          >
            <nav aria-label="Mobile">
              <ul role="list" className="space-y-4">
                {navItems.map(({ label, to }, i) => (
                  <li key={to} className="overflow-hidden">
                    <motion.div
                      initial={reduced ? false : { y: '100%' }}
                      animate={{ y: '0%' }}
                      transition={{ duration: reduced ? 0 : DURATION.base, delay: reduced ? 0 : 0.08 + i * 0.06, ease: EASE.outQuint }}
                    >
                      <NavLink
                        to={to}
                        onClick={() => setOpen(false)}
                        className={({ isActive }) =>
                          `block font-bold leading-none tracking-tight transition-colors duration-200 ${
                            isActive ? 'text-vermilion' : 'text-cream hover:text-vermilion'
                          }`
                        }
                        style={{ fontSize: 'clamp(2.5rem, 12vw, 4rem)', letterSpacing: '-0.03em' }}
                      >
                        {label}
                      </NavLink>
                    </motion.div>
                  </li>
                ))}
              </ul>
            </nav>

            <div className="mt-auto flex items-center justify-between gap-6">
              <Button href="/contact">Start a project</Button>
              <SocialLinks />
            </div>
          </motion.div>
        )}
      </AnimatePresence>
    </div>
  )
}
```

Note: the overlay sits at `z-[55]`, under the `z-[60]` header, so the logo and toggle stay visible and clickable above it.
